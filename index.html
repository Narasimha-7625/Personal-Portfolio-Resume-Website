Visualizing the CSS Box Model

In CSS, every HTML element is wrapped in a rectangular box containing four nested layers: Margin, Border, Padding, and Content.

MARGIN (Outside whitespace, separates elements)
BORDER (Visible perimeter edge)
PADDING (Internal breathing space between content & border)
CONTENT (Text, Image, or Canvas)

Key Viva Concept: box-sizing: border-box;

By default, browsers use box-sizing: content-box, where padding and borders add to the element's specified width, often causing layout overflows. In this project, we set * { box-sizing: border-box; }, ensuring that width includes content, padding, and border.

Answer: Semantic elements (like <header>, <nav>, <main>, <section>, <article>, and <footer>) clearly describe their meaning and role to both the browser and developer, enhancing accessibility and SEO. Non-semantic elements (like <div> and <span>) carry no inherent meaning and act solely as generic styling containers.
Answer: The four components are:
  1. Content: Where text and media appear.
  2. Padding: Clear space around content inside the border.
  3. Border: Line surrounding padding and content.
  4. Margin: Transparent space outside the border separating neighboring elements.
Answer: With content-box (the default), adding padding or borders expands the element's actual rendered width beyond the declared width property. With border-box, padding and border are included within the specified width, making responsive layout sizing predictable.
Answer: Flexbox is one-dimensional (dealing with either rows OR columns at a time), perfect for navigation bars, button rows, and linear stacks. CSS Grid is two-dimensional (handling both rows AND columns simultaneously), making it ideal for overall page layouts and card grids.
Answer:
  • Relative: Positioned relative to its normal position in document flow.
  • Absolute: Removed from normal flow, positioned relative to its nearest positioned ancestor.
  • Sticky: Toggles between relative and fixed depending on scroll offset (used for our navigation bar with position: sticky; top: 0;).
Answer: An internal link uses anchor hash tags (e.g., <a href="#projects">) to navigate to elements with matching ids within the same page. An external link points to an external URL (e.g., <a href="https://github.com" target="_blank" rel="noopener noreferrer">).
Answer: <thead> groups header content, <tbody> groups body content, and <th> designates header cells (which are bold and centered by default and read by screen readers as column/row titles via scope="col").
Answer: The for attribute on a <label> matches the id of an <input>. This pairs them for screen reader accessibility and allows users to click the text label to focus the input directly.
Answer: Transitions require a trigger state change (such as :hover or :focus) to smoothly interpolate between two property values. Keyframe animations (@keyframes) can run automatically on page load without user interaction and can progress through multiple intermediate states (0%, 50%, 100%).
Answer: The <canvas> element is an HTML tag that acts as a blank bitmap drawing surface. JavaScript accesses its rendering context using canvas.getContext("2d") to draw paths, shapes, text, and animations in real time using methods like arc(), lineTo(), and clearRect().
Answer: <meta name="viewport" content="width=device-width, initial-scale=1.0"> tells mobile browsers to set the width of the page equal to the device screen width, preventing mobile browsers from shrinking desktop layouts into tiny unreadable zooms.
Answer: Media queries (e.g. @media (max-width: 768px) { ... }) allow us to apply specific CSS rules only when the screen size meets specific conditions, such as converting a multi-column flex/grid layout into a single column on mobile devices.
